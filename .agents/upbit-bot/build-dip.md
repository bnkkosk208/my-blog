# Build 지침 — 새 전략 "조정 매수"(dip) 추가

## 사용자 요구 (확정)
- 매수: **전일 종가 대비 10% 이상 하락**하면 매수
- 매도: **매수가 대비 10% 이상 상승**하면 매도(익절)
- 손절선: **매수가 대비 10% 이상 하락**하면 매도(손절). 비율은 설정에서 바꿀 수 있게
- 기존 전략(변동성 돌파·이동평균·RSI)은 **그대로 남기고**, 새 전략을 추가해 **처음 선택값(기본 전략)** 으로 한다

## 수정 가능한 범위
`apps/upbit-bot/` 안(spec.md·review.md 제외). 블로그 파일·다른 앱·`.agents/` 수정 금지. 커밋·push 금지. 실 키·실주문 금지.

## 전략 규격 (id: `dip`, 이름: `조정 매수`)
- 캔들: 일봉(`days`). 업비트 일봉은 KST 09:00 시작이므로 "전일 종가" = 직전 일봉(마지막 형성 캔들 바로 앞)의 종가 `c`.
- 파라미터(PARAM_SPECS, 기본값): `dropPct` 하락 매수 % = 10 (1~50), `risePct` 상승 매도 % = 10 (1~100), `stopPct` 손절 % = 10 (1~50). 손절 끄기 옵션은 두지 않는다(사용자가 손절선 두기를 선택).
- 평가(실시간 가격 기준, 변동성 돌파처럼 가격 수신마다 판정):
  - 보유 중: `price >= 매수가 × (1 + risePct/100)` → 매도(사유 "목표 수익 도달 +N%"), `price <= 매수가 × (1 − stopPct/100)` → 매도(사유 "손절 −N%"). 둘 다 아니면 보유. 매수가는 포지션의 평균 매수가(수수료 반영 방식은 기존 포지션 필드 기준을 따르고 코드에 명시).
  - 미보유: 기준가 = 전일 종가, 매수가격선 = 기준가 × (1 − dropPct/100). `price <= 매수가격선` → 매수(사유 "전일 종가 대비 −N% 조정"). **같은 일봉(같은 날)에는 1회만 진입**(memo.enteredDay, 손절 직후 같은 날 재매수 방지).
  - 보유 기간 제한 없음(다음날 자동 청산 없음 — vb와 다름).
- indicators: `prevClose`, `buyLine`, 보유 시 `takeProfit`, `stopLine`. 차트에 매수가격선(미보유)·익절선/손절선(보유)을 점선으로 표시하고 범례 추가.
- 설명 문구(desc)에 "BTC 같은 대형 코인은 하루 10% 하락이 드물어 몇 주·몇 달 동안 매수가 없을 수 있음"을 포함.

## 함께 맞출 곳
- `lib/strategies.js`(STRATEGIES, PARAM_SPECS, candleUnitOf, minCandlesFor, validateParams, evaluate)
- `lib/bot.js`: vb 전용으로 분기된 부분(일봉 사용, 가격 기반 평가, scheduleNext, 다음날 청산 timer)을 dip에도 맞게 — dip은 다음날 청산이 없다. 기존 설정 탭의 손절·익절(기본 OFF)과 함께 켜져 있어도 이상 동작이 없게.
- `lib/backtest.js`: 일봉 백테스트에서 dip 판정(장중 저가가 매수가격선 이하면 매수가격선에 체결, 보유 중 고가가 익절선 이상이면 익절선에 체결, 저가가 손절선 이하면 손절선에 체결 — 같은 캔들에서 둘 다 닿으면 보수적으로 손절 우선)을 정의하고 화면에 그 가정을 표시.
- `index.html`/`main.js`/`ui/*`: 전략 선택 라디오 첫 번째에 "조정 매수" 추가, 파라미터 입력, 상태 줄(예: "전일 종가 98,000,000 · 매수가격선 88,200,000 · 현재 −3.2%"), 기본 전략 `dip`. 기존 저장값이 있는 사용자는 저장된 전략을 유지하되, 저장값이 없으면 dip.
- `tests/`: dip 계산 케이스(매수가격선, 정확히 −10% 경계, 익절·손절 경계, 같은 날 재진입 금지, 백테스트 체결가) 추가. 기존 테스트 유지.
- 서버(`server/`)는 수정 불필요(주문 API는 그대로).
