# Review 서브에이전트 지침 — 업비트 자동매매 (upbit-bot)

## 역할
Build와 분리된 검증자로서 `apps/upbit-bot/`이 spec대로, 브라우저에서 정상 동작하는지, 코드에 문제(특히 보안·돈 관련 버그)가 없는지 확인하고 `apps/upbit-bot/review.md`를 작성한다.

## 수정 가능한 범위
- `apps/upbit-bot/review.md` 작성.
- 발견한 문제의 **수정**은 `apps/upbit-bot/` 안(spec.md 제외)에서만 허용. 수정한 것은 review.md에 전/후와 이유를 기록. 큰 설계 변경이 필요하면 고치지 말고 보고만 한다.
- 블로그 파일·다른 앱·`.agents/` 수정 금지. 커밋·push 금지. 실 키 사용·실주문 금지. 스크린샷 등 임시 파일은 스크래치 디렉터리(`/tmp/claude-0/.../scratchpad` 또는 OS 임시폴더)에 두고 저장소에 남기지 않는다.

## 먼저 읽을 것
`CLAUDE.md`, `apps/upbit-bot/spec.md`(특히 8장 검증 체크리스트), `.agents/upbit-bot/build-share.md`(배포 요구사항).

## 검증 항목
1. **자동 테스트**: `cd apps/upbit-bot && npm test`, `node server/sign-check.js`, 모든 JS `node --check`.
2. **로직 독립 검증**: 테스트를 그대로 믿지 말고 spec 8장 예시값(RSI, 이동평균, 변동성 돌파 목표가, 수수료·모의 체결 손익, 호가 단위 경계값, 최소 주문 5,000원)을 직접 계산해 대조. 돈 계산의 반올림·부동소수 오류, 중복 매수, 매도 수량이 보유량 초과, 수수료 이중 차감 등을 코드 리딩으로 찾는다.
3. **브라우저 동작(Playwright, 사전 설치됨: `require('playwright')`, `chromium.launch()`)**:
   - 이 환경은 api.upbit.com이 차단돼 있을 수 있다. `page.route`로 업비트 REST(마켓 목록, 캔들, 현재가)를 **가짜 응답**으로 대체하고, 웹소켓은 실패하도록 두어 REST 폴링 폴백이 동작하는지 본다. 또 모든 네트워크를 막았을 때 "시세 연결 실패, 재시도 중" 표시가 나오고 화면이 깨지지 않는지 본다.
   - `python3 -m http.server` 또는 `node server/server.js`(가짜 키, DRY_RUN=true, 임시 사본 폴더)로 서빙.
   - 확인: 초기 렌더, 콘솔 오류 0, 마켓 선택, 차트 그리기, 전략 선택·파라미터 변경, 백테스트 실행, 모의 봇 시작/정지·로그·평가손익 갱신, 긴급 정지, 설정 초기화, 하단 버전 v1.0.0, 위험 고지, 실거래 진입 4단계 확인 흐름(블로그 iframe 안에서는 실거래 차단, 로컬 서버 출처에서만 허용), DRY_RUN 서버와의 LiveBroker 연동.
   - 375px(가로 스크롤 없음, 터치 44px)·데스크톱·다크 모드 스크린샷을 찍어 직접 본다.
   - 블로그 메인 iframe 상황(높이 720)도 확인.
4. **로컬 서버 보안**: 127.0.0.1 바인딩, 토큰 없는/틀린 요청, 외부 Origin·Host 위조, 경로 탐색, `.env` 노출, 한도 우회(금액·횟수·마켓·지정가), 키가 로그·응답·에러 메시지에 노출되지 않음, 출금/입금 엔드포인트 부재, JWT·query_hash 생성 규격(spec 기준).
5. **배포(각자 설치형)**: 개인정보 하드코딩 0건(`grep -rn 'bnkkosk\|bnk.kosk' apps/upbit-bot --exclude=spec.md`), `.env` 없이 첫 실행 흐름, README가 비개발자 기준으로 따라 할 수 있는지, `.gitignore`로 `.env` 제외되는지(`git check-ignore`), 면책 문구 일관성.

## review.md 형식
요약(통과/조건부/실패) → 항목별 결과 표 → 발견한 문제(심각도 높음/중간/낮음, 위치 `파일:줄`, 재현, 조치: 수정함/보고만) → 수정 내역 → 확인 못 한 것(공식 문서 미확인 항목 포함) → 블로그 임베드 시 참고(추천 iframe 높이 등).
