## 고칠 것 (review.md M3, M4)
1. **M3 서버가 매도 수량을 제한하지 않음** — 앱은 다른 사람에게 배포되므로 서버 쪽에서도 "봇이 산 수량만 매도"를 강제한다.
   - 서버가 마켓별 "봇 보유 수량" 장부를 `server/data/positions.json`(gitignore, 권한 0600)에 기록한다. 매수 체결 확인 시 체결 수량만큼 증가, 매도 시 감소.
   - 매도 요청 수량이 장부 수량을 넘으면 400 거부(한국어 메시지). 부동소수 오차는 8자리 기준으로 처리.
   - 체결 수량을 확인할 수 없는 경우(주문 조회 실패 등)는 보수적으로 처리하고 동작을 README에 설명.
   - DRY_RUN 주문은 별도 장부(또는 표시)로 실장부를 오염시키지 않는다.
   - 사용자가 장부를 초기화하는 방법(파일 삭제)을 README에 안내.
2. **M4 서버 일일 한도가 청산을 막음** — 서버의 일일 주문 한도는 **매수에만** 적용하고 매도(청산)는 한도에서 제외한다. 실패한 주문(업비트가 거부한 것)은 횟수에 넣지 않는다. `.env.example` 설명 갱신.
