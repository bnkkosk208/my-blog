# Build 서브에이전트 수정 지침 — 2048 리뷰 반영

## 역할
`apps/2048/review.md`에서 발견된 문제를 수정한다.

## 수정 가능한 범위
- `apps/2048/main.js`, `apps/2048/index.html`, `apps/2048/style.css`, 필요하면 `apps/2048/game.js`
- **수정 금지**: `spec.md`, `review.md`, 블로그 파일, `.agents/`, `.claude/`. git 커밋하지 않는다.

## 수정할 문제 (review.md "발견한 문제" 참고)
1. **저장된 점수가 최고 점수를 올림** (`main.js` 로드 부분): 저장된 게임을 불러올 때는 최고 점수를 갱신하지 않는다. 최고 점수는 실제 이동으로 점수가 오를 때만 갱신한다.
2. **되돌리기 후 포커스 유실**: 되돌리기 버튼이 비활성화될 때 그 버튼에 포커스가 있었다면 보드로 포커스를 옮긴다. 오버레이 안의 되돌리기도 동일하게, 오버레이가 닫히면 보드에 포커스.
3. **오버레이 모달 처리** (`index.html` 오버레이, `main.js`): 오버레이에 `role="dialog"`, `aria-modal="true"`, 제목과 연결된 `aria-labelledby`를 둔다. 열려 있는 동안 Tab/Shift+Tab 포커스가 오버레이 버튼 안에서만 순환하게 한다. 이벤트 리스너가 열 때마다 누적되지 않게 한다.
4. **64 타일 글자색 통일** (`style.css`): 64 타일 글자도 다른 중간 값 타일과 같은 진한 갈색 `#3b2f25`로 바꾼다. 64 배경 `#f65e3b`과의 대비가 3:1 이상인지 계산해 확인한다.

review.md의 4번(520px iframe에서 22px 스크롤)은 Embed 단계에서 iframe 높이 560px을 쓰므로 수정하지 않는다.

## 확인
- `node --check`로 수정한 JS 파일 문법 확인.
- 기존 `game.js` 테스트가 있다면 다시 실행해 통과 확인.

## 보고
수정한 파일·위치, 각 문제의 처리 방법, 64 타일 대비 계산값을 반환한다.
