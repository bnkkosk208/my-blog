# Review 서브에이전트 지침 — 런던 여행 앱 v7: 날짜별 날씨 예보

## 역할
Review 단계 담당. Build와 분리된 독립 검증자다. 구현자 보고를 믿지 말고 직접 확인한다.

## 수정 허용 범위
- `apps/london-trip/review.md`: 기존 내용 유지, 맨 끝에 **"## v7 날짜별 날씨 예보 리뷰"** 절 추가.
- 문제를 고칠 때만: `apps/london-trip/weather.js`, `app.js`, `style.css`, `index.html`
그 외 파일은 수정하지 않는다. git 커밋하지 않는다.

## 검증 기준
- `spec.md` 18장 + 끝의 "18.x 사용자 확정"(기본안).
- 실제 Open-Meteo 응답을 직접 받아(curl) 앱 표시값(아이콘·최고/최저·강수·우산 안내)과 대조. WMO 코드 → 한국어/이모지 매핑이 공식 WMO 코드표와 맞는지.
- 외부 요청이 Open-Meteo 한 곳뿐인지(네트워크 요청 목록), 토글 끄면 요청 0, 캐시 3시간, 실패·오프라인·타임아웃 시 앱 정상, 응답 값 textContent 렌더(XSS), null 처리.
- 출처 표기(링크, CC BY 4.0).
- 회귀: 65행, 금액, 알림, 자동 이동, 한국 시각, 사진, 스와이프, 자동 완료, 360/375px 가로 스크롤 없음(날짜 탭 높이 68px 변경 포함, 자동 이동의 sticky 높이 보정이 여전히 맞는지), 콘솔 에러 0, 블로그 메인 iframe, 다크/라이트.

## Build가 spec과 다르다고 한 점 (타당성 판단)
1. 전역 이름 `TripWeather`
2. 지난 날짜 값 보존을 위한 캐시 병합(최대 40일)
3. 업데이트 시각 런던·한국 병기
4. 지난 날짜 요약 "(지난 예보)", 우산 안내 생략
5. 날짜 탭 높이 56→68px
6. 출처 표기 두 곳

## 브라우저 검증
