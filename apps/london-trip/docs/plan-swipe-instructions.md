# Plan 서브에이전트 지침 — 런던 여행 앱 v5: 사진 기본 펼침 + 일자 좌우 스와이프

## 역할
Plan 단계 담당. 코드는 작성하지 않는다. **간결하게**(70줄 이내).

## 수정 허용 범위
- `apps/london-trip/spec.md` 맨 끝에 **"## 16. 사진 기본 펼침 + 일자 스와이프 (v5)"** 절 추가만. 기존 1~15장은 수정하지 않는다(대체 규칙은 16장에 명시). 다른 파일은 건드리지 않는다.

## 사용자 요구
"사진은 기본값으로 펼치기로 해주고, 일정 페이지에서 일자별로는 좌우 스와이핑 기능을 넣어줘."

## A. 사진 기본 펼침
- 현재: 사진은 카드를 펼쳐야 보이고 접힌 카드에는 🖼 표시만(15장 C3).
- 목표: 사진이 있는 카드는 **처음부터 사진이 보이게**. 해석 두 가지를 비교하고 기본안 제시:
  1. 접힌 카드에도 사진(썸네일/16:9)을 항상 표시, 나머지 상세(비고·추천·메모)는 기존처럼 펼치기.
  2. 사진 있는 카드를 기본으로 펼친 상태로 시작.
- 기존 "사진 표시" 토글, `loading="lazy"`, 자동 이동(14장, 스크롤 위치 계산 — 이미지 로드로 레이아웃이 밀리지 않도록 width/height), 완료 항목 흐림 처리와의 관계.

## B. 일자 좌우 스와이프
- 일정 뷰에서 타임라인 영역을 좌/우로 스와이프하면 이전/다음 날(Day 1~8 경계에서 멈춤).
- 세로 스크롤과 구분(수평 이동 거리·각도 임계값), 짧은 탭·텍스트 선택·입력 요소·select·사진 크게 보기 dialog·바텀시트 위에서는 무시, 멀티터치 무시.
- 구현: Pointer Events 또는 Touch Events(passive), `touch-action: pan-y`. 외부 라이브러리 없음. (선택) 손가락 따라 살짝 움직이는 피드백 + 전환 애니메이션, `prefers-reduced-motion` 시 즉시.
- 스와이프는 사용자 조작 → 14장 자동 이동 3분 보류 규칙 적용. 날짜 탭 스크롤 위치 동기화, 화면 상단으로 스크롤 여부.
- 데스크톱 마우스 드래그 지원 여부(기본안: 터치만), 키보드 좌우 화살표는 기존 탭 규칙 유지. 스와이프 가능 안내(첫 사용 힌트 여부).
- iframe 안에서 부모 페이지 스크롤/뒤로가기 제스처(iOS 가장자리 스와이프)와 충돌.

## 공통
- 변경 파일(app.js, style.css, index.html), localStorage 추가 여부.
- 완료 기준(Review 체크리스트): 스와이프 시뮬레이션 방법(합성 PointerEvent/TouchEvent 디스패치), 세로 스크롤 오인 없음, 경계, 회귀(65행·금액·알림·자동 이동·한국 시각·사진 캡션).
