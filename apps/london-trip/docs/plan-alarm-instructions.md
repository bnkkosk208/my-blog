# Plan 서브에이전트 지침 — 런던 여행 앱 v2: 알림 기능

## 역할
Plan 단계 담당. 코드는 작성하지 않고 계획만 작성한다.

## 수정 허용 범위
- `apps/london-trip/spec.md` 맨 끝에 **"## 13. 알림 기능 (v2)"** 절을 추가하는 것만 허용.
- 기존 1~12장 내용은 수정하지 않는다(필요하면 13장 안에서 "12.x를 대체" 식으로 명시). 다른 파일은 건드리지 않는다.

## 사용자 요구
"일정 항목으로 푸시 알림 기능 넣어줘." — 일정 항목별로 시작 전에 알려 주는 기능.

## 사용자 확정 방식 (비교 후 결정됨 — 다시 묻지 말 것)
**브라우저 알림(Notification API) + 캘린더 내보내기(.ics, VALARM)** 조합.
- 앱이 열려 있을 때: 시스템 알림(권한 허용 시) + 앱 내 토스트(권한 거부·미지원·iframe일 때 대체).
- 앱이 닫혀 있을 때: .ics로 휴대폰 캘린더에 넣어 OS가 알림.
- 서버 푸시(외부 서비스)는 범위 밖. 아래 "방식 비교"는 각 방식의 제약을 13장에 짧게 기록하는 용도로만 쓴다.

## 현재 앱 (먼저 읽을 것)
- `apps/london-trip/spec.md`, `review.md`, `index.html`, `app.js`, `store.js`, `time.js`, `data.js`
- 순수 HTML/CSS/JS, 일반 `<script defer>`, localStorage 키 `london-trip:v1:*`, 런던 시각은 `TripTime`(Intl, Europe/London)
- GitHub Pages(정적 호스팅, HTTPS) 배포, 블로그 메인에 iframe으로도 삽입됨. 서버·푸시 서버 없음.

## 반드시 다룰 제약과 방식 비교
정적 사이트라 서버 푸시가 불가능하다. 다음 방식을 비교하고 조합을 제안하라(각각 동작 조건·플랫폼 제약 명시: Android Chrome, iOS Safari, 데스크톱, iframe 안).
1. **앱 내 알림**: 페이지가 열려 있을 때 정해진 시각에 토스트/배너 + (선택) 진동 `navigator.vibrate` + (선택) 짧은 소리(Web Audio, 사용자 제스처 후에만).
2. **브라우저 Notification API**: 권한 요청, 탭이 열려 있을 때만 동작(백그라운드 탭 타이머 지연 포함), iOS는 홈 화면 추가 PWA에서만 가능하다는 점, iframe 안에서 권한 요청 불가/제한.
3. **캘린더 내보내기(.ics, VALARM 포함)**: 일정을 휴대폰 기본 캘린더에 넣어 OS가 알림을 보내게 하는 방식. 앱이 닫혀 있어도 동작하는 유일하게 확실한 방법. 시간대(`TZID=Europe/London` 또는 UTC 변환), r02/r66 같은 시간대 혼재 행 처리, 하루 단위/전체/선택 항목 내보내기, 사용자 일정 포함 여부.
4. (참고만) Service Worker + Push / Notification Triggers — 서버 필요 또는 표준 폐기로 범위 밖인 이유.

## 계획에 담을 내용
- 알림 설정 UI: 항목별 알림 켜기/끄기(벨 아이콘), 몇 분 전 알림(기본값 제안, 예: 10/30/60분), 일괄 설정(예: 예약필요 항목·이동 항목만 켜기), 전역 켜기/끄기.
- 다가오는 알림 목록(오늘/다음 알림 표시) 위치.
- localStorage 키 설계(`london-trip:v1:alarm` 등)와 스키마 검증, 기존 백업(S2) 내보내기/가져오기에 포함.
- 스케줄링 로직: 기존 1분 타이머 재사용 여부, 이미 울린 알림 중복 방지(fired 기록), 탭 복귀 시 놓친 알림 처리(예: 15분 이내면 표시), 런던 시각 기준.
- 사용자 일정(custom) 알림 지원, 시작시간 없는 행 처리.
- 접근성(aria-live), 다크모드, 터치 타깃 44px.
- 엣지 케이스, 완료 기준(Review 체크리스트 — 시간 고정(`TripTime.now`)으로 알림 발생 확인하는 방법 포함).
- 파일별 변경 범위(어떤 파일을 고칠지; 새 파일이 필요하면 예: `alarm.js`).
- **사용자 결정 필요** 항목을 표로(예: 어떤 방식 조합으로 갈지, 기본 알림 시점).
