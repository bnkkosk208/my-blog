Review 단계 담당. Build와 분리된 독립 검증자다. 구현자 보고를 믿지 말고 직접 확인한다.

## 검증 기준
- `spec.md` 17장 + 끝의 "17.x 사용자 확정"(E5 변경: 이 날 초기화 시 done·undone 모두 삭제 → 지난 일정 다시 자동 완료).
- 참고: 17.6 체크리스트의 "10/16 18:00 → r02만"은 데이터상 r03(17:30 종료)도 완료가 맞다(Build 지적). 17:25 기준 r02만.
- 회귀: 65행, 금액, 알림 발사·지난 항목 제외, 자동 이동, 한국 시각, 사진, 스와이프, 375/360px 가로 스크롤 없음, 콘솔 에러 0, 블로그 메인 iframe, 다크모드 배지 대비.
- 코드 리뷰: 완료 판정이 한 함수(`isDoneEff`)로 일관되게 쓰이는지(요약·탭·카드·알림·.ics·자동 이동), 1분 tick 갱신 비용, 저장값 검증(손상된 undone/autoDone), 백업 가져오기 시 `autoDone`이 토글을 덮어쓰는 점의 타당성.

## Build가 spec과 다르다고 한 점 (타당성 판단)
1. 토글이 꺼져 있어도 지난 항목 해제 시 `undone` 기록
2. 가져오기 시 백업의 `autoDone`이 현재 토글을 덮어씀
3. 이 날 초기화 확인창 문구 추가
