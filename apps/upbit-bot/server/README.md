# 업비트 자동매매 봇: 설치·실행 안내 (처음 쓰는 분용)

이 프로그램은 **각자 자기 PC에 설치해서** 씁니다. 내 업비트 API 키는 **내 PC의 `.env` 파일에만** 들어가고,
프로그램을 나눠 준 사람(배포자)을 포함해 누구에게도 전달되지 않습니다. 중앙 서버나 회원가입은 없습니다.

> **꼭 읽어 주세요(면책 고지)**
> 이 프로그램은 본인 계좌·본인 판단·본인 책임으로 쓰는 학습·실험용 도구입니다. 투자 권유가 아니며 수익을 보장하지 않습니다.
> 가상자산은 원금 전액을 잃을 수 있습니다. 배포자는 투자 손실과 API 키 관리 문제에 책임지지 않습니다.
> 업비트(두나무)와 관련 없는 비공식 도구입니다. 전문은 `../DISCLAIMER.md`에 있습니다.

모의투자(가상 잔고)만 쓰실 거라면 설치할 필요가 없습니다. 블로그의 앱 화면에서 바로 쓸 수 있습니다.
아래 과정은 **내 계좌로 실거래**를 하려는 경우에만 필요합니다.

---

## ① Node.js 설치
1. https://nodejs.org 에 들어가 **LTS**라고 적힌 버전을 내려받아 설치합니다(설치 화면은 모두 "다음"으로 진행해도 됩니다).
2. 버전 18 이상이면 됩니다. 이미 설치되어 있다면 이 단계는 건너뜁니다.

## ② 프로그램 내려받기
1. 배포자가 알려 준 GitHub 저장소 페이지에서 초록색 **Code** 버튼 → **Download ZIP**을 누릅니다.
2. ZIP 압축을 풀고, 그 안의 `apps/upbit-bot` 폴더**만** 원하는 곳(예: 문서 폴더)으로 복사합니다.
   이후 안내의 "프로그램 폴더"는 이 `upbit-bot` 폴더를 말합니다.

## ③ 업비트 Open API 키 발급
1. 업비트 웹사이트 → 마이페이지 → **Open API 관리**로 들어갑니다.
2. 권한은 **"자산조회"와 "주문하기"만** 체크합니다("주문조회"가 따로 있으면 함께 체크).
   **출금 권한은 절대 체크하지 마세요.** 이 프로그램에는 출금·입금 기능이 없고, 앞으로도 넣지 않습니다.
3. 허용 IP에는 **본인 PC의 공인 IP**만 등록합니다. 인터넷 검색창에 "내 IP 확인"을 검색하면 나옵니다.
4. 발급된 Access Key와 Secret Key를 복사해 둡니다. Secret Key는 발급할 때 한 번만 보이니 잘 보관하세요.

## ④ 설정 파일(.env) 만들기
1. 프로그램 폴더 안의 `server` 폴더에서 실행 파일을 더블클릭합니다(⑤ 참고). 처음 실행하면
   `server/.env` 파일이 자동으로 만들어지고 프로그램이 안내 문구를 보여 준 뒤 종료됩니다.
2. `server/.env`를 메모장(Windows) 또는 텍스트 편집기(Mac)로 엽니다.
   - Mac에서는 이름이 `.`으로 시작해 숨겨져 있습니다. Finder에서 `Command + Shift + .`을 누르면 보입니다.
3. 다음 두 줄의 `여기에_...` 부분을 내 키로 바꾸고 저장합니다.
   ```
   UPBIT_ACCESS_KEY=내_액세스키
   UPBIT_SECRET_KEY=내_시크릿키
   ```
4. 나머지 항목(포트, 1회 최대 금액, 하루 주문 횟수, 허용 마켓 등)은 파일 안의 한국어 설명을 보고 필요할 때만 바꿉니다.
   기본값은 안전 모드(`DRY_RUN=true`), 1회 50,000원, 하루 10회, KRW-BTC만 허용입니다.

## ⑤ 실행
- **Windows**: `server/start-windows.bat`를 더블클릭합니다.
- **Mac**: `server/start-mac.command`를 더블클릭합니다.
  - "실행 권한이 없습니다"가 나오면 터미널에서 `chmod +x ` 뒤에 파일을 끌어다 놓고 Enter를 누른 다음 다시 더블클릭합니다.
  - "확인되지 않은 개발자" 경고가 나오면 파일을 우클릭 → **열기**를 선택합니다.
- 터미널에 익숙하다면: `cd server` 후 `node server.js`

검은 창(터미널)에 `브라우저에서 http://127.0.0.1:8787/ 을 여세요`가 나오면 그 주소를 브라우저로 엽니다.
**처음 실행할 때 한 번만** `로컬 토큰`이 표시됩니다. 이 값은 `.env`의 `LOCAL_TOKEN`에도 저장되어 있으니 잊어버리면 거기서 확인하세요.
검은 창을 닫으면 서버도 꺼집니다. 쓰는 동안은 열어 두세요.

## ⑥ 처음에는 DRY_RUN으로 충분히 시험하기
- `.env`의 `DRY_RUN=true`(기본값)이면 주문을 업비트로 **보내지 않고**, "보냈을 요청 내용"만 로그에 남깁니다(`[DRY-RUN]` 표시).
- 앱 상단의 **실거래** 버튼 → 위험 고지 읽기 → 확인 체크 4개 → 로컬 토큰과 `실거래 시작` 입력 순서로 들어갑니다.
- 서버 칩이 `● 서버 연결됨(DRY-RUN)`으로 보이면 정상입니다. 잔고 조회는 실제로 하므로 키·IP 설정이 맞는지도 확인됩니다.
- 며칠 동안 봇이 원하는 대로 매수·매도 신호를 내는지 지켜보세요.

## ⑦ 실거래로 전환하기 (본인 판단과 책임으로)
1. 검은 창을 닫아 서버를 끕니다.
2. `.env`에서 `DRY_RUN=false`로 바꾸고 저장합니다.
3. 다시 실행하면 서버 칩이 `● 서버 연결됨(실주문)`으로 바뀝니다. 이때부터는 **실제 주문**이 나갑니다.
4. 실거래에서 서버를 켜면 API 키 만료일을 확인해, 만료가 가까우면 경고를 띄웁니다.
- 봇은 **브라우저 탭이 열려 있는 동안만** 동작합니다. 탭을 닫거나 PC가 절전되면 멈춥니다.
- 봇은 자신이 산 수량만 매도합니다. 원래 갖고 있던 코인은 건드리지 않습니다.

## ⑧ 키가 유출된 것 같다면
1. **즉시** 업비트 → Open API 관리에서 해당 키를 **삭제**합니다.
2. 업비트 거래·입출금 내역을 확인합니다.
3. 새 키를 발급해 `.env`에 다시 넣습니다.
`.env` 파일은 메신저·이메일·클라우드 공유 폴더로 보내지 마세요. 프로그램을 다른 사람에게 줄 때는 `.env`를 빼고 주세요.

## ⑨ 새 버전으로 업데이트하기
1. 서버를 끕니다.
2. `server/.env` 파일을 다른 곳에 복사해 둡니다(**이 파일만 내 것**입니다).
3. ② 방법으로 새 버전을 내려받아 프로그램 폴더를 통째로 덮어씁니다.
4. 복사해 둔 `.env`를 `server` 폴더에 다시 넣습니다.
5. 새 `.env.example`에 새 항목이 생겼다면 필요한 줄만 내 `.env`에 옮겨 적습니다.
화면 맨 아래에 앱 버전(예: v1.0.0)이 표시됩니다. 모의 계좌·로그는 브라우저에 저장되어 있어 업데이트해도 유지됩니다.

## ⑩ 자주 묻는 문제
| 증상 | 해결 |
|---|---|
| `포트 8787이(가) 이미 사용 중입니다` | 서버가 이미 켜져 있는지 확인하세요(다른 검은 창). 아니면 `.env`의 `PORT`를 8788 등으로 바꾸고 그 주소로 여세요. |
| `허용되지 않은 IP입니다` / `no_authorization_i_p` | 업비트에 등록한 허용 IP와 지금 PC의 공인 IP가 다릅니다. 공유기 재시작, 와이파이 변경, 통신사 사정으로 바뀔 수 있습니다. "내 IP 확인"으로 확인 후 다시 등록하세요. |
| `API 키 인증 실패(JWT 검증 오류)` | 키를 잘못 복사했거나(앞뒤 공백 포함) 키가 삭제·만료되었습니다. `.env`를 다시 확인하세요. PC 시계가 크게 틀려도 인증이 실패할 수 있으니 시간 자동 동기화를 켜세요. |
| `nonce_used`(중복 요청) | 대부분 일시적입니다. 계속되면 PC 시계를 맞추고 서버를 다시 켜세요. |
| `⚠ 인증 실패`(로컬 토큰) | 화면에 넣은 토큰이 `.env`의 `LOCAL_TOKEN`과 다릅니다. 설정 탭의 "토큰 지우기" 후 다시 입력하세요. 5번 틀리면 1분간 잠깁니다. |
| `서버에 API 키가 설정되지 않았습니다` | `.env`의 키를 바꾸고 저장한 뒤 서버를 다시 켜세요. |
| `허용되지 않은 마켓입니다` | `.env`의 `ALLOWED_MARKETS`에 해당 마켓을 추가하고 서버를 다시 켜세요. |
| 실거래 버튼이 눌리지 않음 | 블로그 화면이 아니라 서버가 알려 준 `http://127.0.0.1:8787/` 주소에서 열어야 합니다. |
| 시세가 안 나옴(`시세 연결 실패, 재시도 중`) | 인터넷 연결을 확인하세요. 회사·학교 네트워크에서는 업비트 접속이 막혀 있을 수 있습니다. |
| 더블클릭하면 창이 바로 닫힘 | Node.js가 설치되지 않았을 수 있습니다. ①을 확인하세요. |

## 참고: 보안 동작
- 서버는 `127.0.0.1`(내 PC)에서만 접속할 수 있고, 다른 사이트에서 오는 요청은 막습니다.
- 브라우저는 로컬 토큰이 있어야 서버 기능을 쓸 수 있습니다(5회 틀리면 1분 잠금).
- 서버가 하는 일은 잔고·주문 조회, 시장가 매수·매도, 주문 취소, 키 만료일 조회뿐입니다. **출금·입금 기능은 없습니다.**
- 허용 마켓, 1회 최대 금액, 하루 주문 횟수, 중복 주문을 서버가 다시 검사합니다.
- `server` 폴더(`.env` 포함)는 브라우저로 열리지 않으며, 키 값은 화면·로그에 출력하지 않습니다. `.env`는 가능하면 본인만 읽을 수 있게(권한 600) 저장합니다.

## 참고: 개발자용
- 테스트: 프로그램 폴더에서 `npm test`(Node 18 이상, 설치할 패키지 없음)
- 서명 확인(실제 키 없이): `npm run sign-check` 또는 `node server/sign-check.js`
- 엔드포인트: `GET /health`(토큰 불필요), `GET /api/session`, `GET /api/accounts`, `GET /api/chance`, `POST /api/orders`(시장가만), `GET·DELETE /api/order`, `GET /api/orders/open`
- 공식 문서로 다시 확인해야 할 값: JWT·`query_hash` 규칙(`upbit-auth.js`), 미체결 조회·키 목록 경로(`server.js`), 수수료·호가 단위(`../lib/market-rules.js`)
