# 면책 및 책임 고지

업비트 자동매매 봇(이하 "이 프로그램") 버전 1.0.0

1. **본인 계좌·본인 판단·본인 책임**
   이 프로그램은 각 사용자가 자기 PC에 직접 설치하고, 자기 업비트 계좌와 자기 API 키로 사용하는 도구입니다.
   실거래 모드에서 나가는 모든 주문과 그 결과는 사용자 본인의 판단이며, 책임도 사용자 본인에게 있습니다.

2. **배포자의 책임 없음**
   배포자(이 프로그램을 공유한 사람)는 사용자의 API 키·계좌·자산에 접근하지 않으며, 이를 보관·관리하지 않습니다.
   배포자는 투자 손실, 수수료, 프로그램 오류, 네트워크·거래소 장애, API 키 유출·관리 소홀로 생긴 손해에 책임지지 않습니다.

3. **수익 보장 없음·투자 권유 아님**
   이 프로그램은 학습·실험용 도구이며 투자 권유나 투자 자문이 아닙니다.
   포함된 전략(변동성 돌파, 이동평균 교차, RSI)과 백테스트 결과는 과거 데이터에 기반하며 미래 수익을 보장하지 않습니다.
   가상자산은 가격 변동이 매우 크고 원금 전액을 잃을 수 있습니다.

4. **API 키 관리**
   API 키는 본인 PC의 `server/.env` 파일에만 두고, 다른 사람에게 보내거나 인터넷에 올리지 마십시오.
   키를 발급할 때 **출금 권한을 절대 부여하지 마십시오.** 허용 IP는 본인 PC의 공인 IP만 등록하십시오.
   키가 유출되었다고 의심되면 즉시 업비트에서 해당 키를 삭제하십시오.

5. **비공식 도구**
   이 프로그램은 업비트(두나무)와 관련이 없는 비공식 도구입니다.

이 프로그램을 설치하거나 실행하면 위 내용에 동의한 것으로 봅니다.
