업비트 자동매매 봇 · 빠른 시작

내 PC에 설치해 소액 실거래까지 ·

모의투자만 할 거라면 설치할 필요가 없어요. 블로그의 앱 화면에서 바로 쓰면 돼요. 아래는 내 업비트 계좌로 실거래할 때만 필요한 과정이에요. 내 API 키는 내 PC에만 저장되고, 누구에게도 전달되지 않아요.

1프로그램 준비

  1. nodejs.org에서 LTS 버전을 설치해요.
  2. GitHub 저장소에서 Code → Download ZIP을 누르고, 압축을 푼 다음 apps/upbit-bot 폴더만 꺼내 둬요.

2업비트 API 키 발급

  1. 업비트 웹 → 마이페이지 → Open API 관리로 가요.
  2. 권한은 ✔ 자산조회 ✔ 주문하기(주문조회가 따로 있으면 그것도)만 체크해요.
  3. ✘ 출금 권한은 절대 체크하지 마세요.
  4. 허용 IP에는 검색창에 “내 IP 확인”을 쳐서 나온 주소를 넣어요.

3설정 파일(.env) 작성

  1. server 폴더의 실행 파일을 더블클릭해요. 윈도우는 start-windows.bat, 맥은 start-mac.command예요. 처음에는 .env 파일만 만들고 꺼져요.
  2. .env를 메모장으로 열어 아래처럼 고치고 저장해요.
UPBIT_ACCESS_KEY=발급받은 액세스키
UPBIT_SECRET_KEY=발급받은 시크릿키
DRY_RUN=true          ← 처음엔 시험 모드
MAX_ORDER_KRW=10000   ← 1회 최대 1만 원
DAILY_MAX_ORDERS=3    ← 하루 매수 3회
ALLOWED_MARKETS=KRW-BTC

4시험 모드로 확인

  1. 실행 파일을 다시 더블클릭해요. 검은 창에 나오는 로컬 토큰을 적어 둬요. 잊어도 .env의 LOCAL_TOKEN 줄에 있어요.
  2. 브라우저로 http://127.0.0.1:8787/에 접속해요.
  3. 실거래 버튼을 누르고 고지문 읽기 → 체크 4개 → 토큰과 “실거래 시작” 입력 순서로 진행해요.
  4. 위쪽 띠가 주황색(시험 모드)이고 내 계좌에 실제 잔고가 보이면 성공이에요.

5소액 실거래 (1만 원)

  1. 검은 창을 닫아요. .env에서 DRY_RUN=false로 바꾸고 다시 실행해요. 위쪽 띠가 빨간색이 되면 실주문 모드예요.
  2. 투자 방식은 고정 · 10000원으로 넣어요.
  3. ▶ 봇 시작을 눌러요. 체결은 로그 탭과 업비트 앱에서 확인해요.
  4. 바로 정리하려면 “보유분 시장가 매도”를 눌러요.

왜 1만 원인가요? 업비트는 5,000원보다 작은 주문은 매도도 받지 않아요. 6,000원어치를 샀다가 손절선(−30%)에 닿으면 4,200원이 남아 팔 수 없어요.

6기본 전략: 조정 매수

매수전일 종가(업비트 일봉, 한국 시간 오전 9시 기준)보다 10% 떨어지면 사요. 하루에 한 번만 사요.
익절산 가격보다 +5% 오르면 팔아요.
손절산 가격보다 −30% 떨어지면 팔아요. 한 번 손절하면 익절 약 6번분의 수익을 잃어요.

큰 코인은 하루에 10% 떨어지는 날이 드물어서 몇 주씩 매수가 없을 수 있어요. 주문 흐름을 바로 시험하려면 매수 하락폭을 잠시 1%로 낮추고, 시험이 끝나면 10으로 되돌려요.

!자주 생기는 문제

허용되지 않은 IPPC의 공인 IP가 바뀌었어요. “내 IP 확인”으로 확인하고 업비트에 다시 등록해요.
포트 8787 사용 중다른 검은 창에서 서버가 이미 켜져 있어요. 그 창을 닫거나 .env의 PORT를 바꿔요.
실거래 버튼이 안 눌려요블로그 주소가 아니라 http://127.0.0.1:8787/에서 열어야 해요.
시세 연결 실패칩 아래에 나오는 원인을 확인하고, 칩을 누르면 바로 다시 연결해요.
봇이 멈췄어요브라우저 탭과 검은 창을 둘 다 켜 둬야 봇이 동작해요.
