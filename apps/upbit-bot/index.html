로컬 서버 연결 (실거래)

실거래는 각자 자기 PC에 apps/upbit-bot 폴더를 내려받아 server를 실행하고, http://127.0.0.1:8787/로 이 앱을 열었을 때만 쓸 수 있습니다. 본인 API 키는 본인 PC의 server/.env에만 넣습니다. 설치 방법은 server 폴더의 README를 보세요.

데이터

설정·모의 계좌·로그·봇 상태는 이 브라우저에만 저장됨 — 서버나 다른 사람에게 전송되지 않으며, 다른 브라우저·기기와 공유되지 않습니다. API 키는 브라우저에 저장하지 않습니다.

투자 위험 고지

모의투자용 학습 도구입니다. 수익을 보장하지 않으며 실거래 손실 책임은 사용자에게 있습니다.

이 페이지는 file://로는 동작하지 않습니다. 로컬에서는 python -m http.server 또는 node server/server.js로 여세요.
